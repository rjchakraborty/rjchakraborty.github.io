RJ Backup Automation

Privacy Policy

Effective date: September 4, 2026

This policy describes how RJ Backup Automation uses Google user data. The utility is a private, single-user program operated by Raja Chakraborty on his own Mac.

Google user data accessed

The utility uses Google Drive authorization to access the operator's Drive files. It lists files in the configured backup folder, uploads encrypted archives and checksum files, reads metadata and checksums for verification, and deletes older files created and managed by this backup automation after a replacement is verified.

How data is used

Google Drive data is used only to perform, verify, and rotate the operator's personal backups. It is not used for advertising, profiling, analytics, or any unrelated purpose.

Storage and security

  • Backup source files are processed locally on the operator's Mac.
  • Archives are encrypted locally before upload.
  • OAuth credentials are stored locally and are not included in cloud backups.
  • The utility has no external application server or user database.

Sharing and disclosure

Google user data is not sold, shared with advertisers, or transferred to third parties. Data moves only between the operator's Mac and the operator's Google Drive through Google's APIs.

Retention and deletion

The latest verified backup is retained in Google Drive. Older automation-managed backups may be removed only after the new encrypted archive and checksum have been uploaded and verified. The operator controls local and Drive retention.

Revoking access

The operator can revoke access at any time from the Google Account third-party connections page. Revocation stops future automated Drive operations until access is explicitly granted again.
